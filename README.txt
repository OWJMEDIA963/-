رقميّات - دليل توافق الشاشات والزقات

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html بمتصفح Chrome أو Edge.
3) اكتب موديل الجهاز أو كود الشاشة في مربع البحث.
4) من زر "إضافة شاشة" أضف كود القطعة وكل الأجهزة المتوافقة معها، وافصل الموديلات بفاصلة.
5) استخدم "تصدير نسخة احتياطية" لحفظ قاعدة بياناتك كملف JSON، ويمكن استيرادها لاحقاً.

ملاحظات مهمة:
- الموقع يعمل HTML/CSS/JavaScript فقط ولا يحتاج سيرفر أو قاعدة بيانات خارجية.
- البيانات الأولية أمثلة تجريبية وليست مرجع توافق موثوقاً. يجب إدخال بيانات موردك أو فحص رقم القطعة والفلاتة قبل اعتماد أي توافق.
- البيانات التي تضيفها تحفظ في LocalStorage على نفس المتصفح والجهاز. لا تنتقل تلقائياً بين الأجهزة أو المستخدمين.
- هذا الإصدار لا يحتوي على تسجيل دخول أو مزامنة سحابية.
