# رقميات — النسخة الآمنة الأولية

موقع عربي RTL لكتالوج قطع الموبايلات مع خادم خلفي، قاعدة بيانات SQLite، حسابات، صلاحيات مدير/موظف، وسجل عمليات.

## المتطلبات
- Node.js 20 أو أحدث
- اتصال إنترنت أول مرة لتنزيل حزم npm

## تشغيل محلياً
1. فك الضغط.
2. انسخ `.env.example` إلى ملف باسم `.env`.
3. ضع قيمة عشوائية قوية لـ `SESSION_SECRET` (32 حرفاً على الأقل). لا تشارك ملف `.env`.
4. افتح Terminal داخل مجلد المشروع ونفّذ:
   ```bash
   npm install
   npm run create-admin
   npm start
   ```
5. افتح `http://localhost:3000` وأنشئ المدير الأول من أداة الطرفية `create-admin` (لن يكون هناك مدير افتراضي أو كلمة مرور ثابتة).

## إدارة الحسابات
بعد تسجيل الدخول بحساب المدير، تظهر لوحة إنشاء الحسابات. المدير وحده يمكنه إنشاء مديرين وموظفين أو تعطيل حساباتهم. اختر كلمات مرور طويلة وفريدة. الحسابات تحفظ كلمات المرور كـ bcrypt hashes، لا كنص صريح.

## كتالوج المورد
لا يوجد مورد محدد في الطلب، لذلك لا يمكن ربط كتالوج حيّ فعلي دون اسم المورد وتوثيق API أو ملف رسمي منه. المشروع يتضمن:
- نموذجاً لإضافة القطع يدوياً إلى قاعدة البيانات.
- إعدادات تكامل اختيارية في `.env`: `SUPPLIER_API_BASE`, `SUPPLIER_API_KEY`, `SUPPLIER_API_TOKEN_HEADER`.
- نقطة API عامة الشكل تتوقع `GET /products/search?q=...` من المورد؛ يجب تعديل `server.js` لتطابق وثائق المورد الفعلية قبل استخدامها. لا تضع مفتاح API في ملفات الواجهة الأمامية.
- لا يستورد هذا المشروع كتالوجاً خارجياً تلقائياً ما لم تُضبط بيانات API الصحيحة.

## التحقق من التوافق
البيانات الأولية فارغة عمداً. لا توجد أي قطعة معتمدة مسبقاً على أنها متوافقة 100%.
- الحالة الافتراضية `unverified` = غير متحقق منه.
- لا يقبل النظام الحالة `verified` إلا مع رقم قطعة ورابط مصدر واسم شخص قام بالتحقق.
- يجب عملياً مطابقة رقم موديل الهاتف الدقيق ورقم القطعة/الفلاتة ونسخة الجهاز مع كتالوج المورد أو اختبار موثق. وجود رابط واسم تحقق وحده ليس ضماناً تقنياً مطلقاً.

## ملاحظات أمنية مهمة قبل نشره على الإنترنت
- استخدم HTTPS خلف reverse proxy مضبوط، وعيّن `NODE_ENV=production` و`SESSION_SECRET` عشوائياً قوياً.
- اجعل مجلد المشروع وقاعدة البيانات غير قابلين للتنزيل عبر الويب، واحتفظ بنسخ احتياطية مشفرة.
- حدّث Node والحزم دورياً، وضع الموقع خلف firewall أو VPN إذا كان لموظفي المحل فقط.
- الجلسات تستخدم HttpOnly وSameSite=Strict وSecure في الإنتاج، مع حماية CSRF ومحدِّد محاولات تسجيل الدخول وHelmet وسجل تدقيق.
- إذا كان الموقع سيعمل على عدة خوادم، انقل الجلسات إلى مخزن مركزي مدعوم بدلاً من SQLite.
- النسخة لا تتضمن استيراد CSV أو اتصالاً حقيقياً بمورد لأن تفاصيل المورد غير متوفرة.

## الجداول
- `users`: الحسابات والأدوار.
- `products`: القطع ومعلومات المورد والتوافق.
- `audit_log`: أحداث الدخول والإدارة.
- `settings`: محجوزة للإعدادات المستقبلية.
